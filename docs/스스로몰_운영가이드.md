# 스스로몰 운영 가이드

스스로몰은 직접 결제를 받지 않고, 판매처(쿠팡·네이버쇼핑·오늘의집·다나와)로 구매를 연결하는 제휴형 몰입니다. 이 문서는 제휴 링크를 등록하고 운영하는 순서를 정리합니다.

> 정책·수수료·승인 조건은 판매처가 수시로 바꿉니다. 아래 수치는 2026년 10월 확인 기준의 참고값이며, 가입 시 각 프로그램의 공식 안내를 반드시 다시 확인하세요.

---

## 1. 구조 한눈에 보기

```
고객 ──▶ 7분 진단 / 자료실 / 스스로몰
            │  공정 판정(직접 / 동행 / 등록업체)
            ▼
        공정별 키트 15종 · 도구·자재 160개
            │  구매 버튼: 쿠팡 · 네이버쇼핑 · 오늘의집 · 다나와 · 전문몰
            ▼
        판매처에서 고객이 직접 결제
            │  '제휴' 링크로 구매된 경우
            ▼
        판매처 → 스스로연구소(주식회사 블랭크) 수수료 지급
```

- **링크는 "판매처:검색어" 단위로 관리합니다.** 예를 들어 `coupang:비접착식 데코타일` 하나에 쿠팡 파트너스 링크를 등록하면, 스스로몰·키트·자료실에서 같은 검색어를 쓰는 모든 쿠팡 버튼에 적용되고 '제휴' 표시가 붙습니다.
- 등록하지 않은 버튼은 판매처 검색 결과로 그냥 열립니다. 수수료는 생기지 않지만 고객 경험은 같습니다.
- 등록업체만 시공할 수 있는 공정(전기 배선·분전반, 소방시설, 가스, 구조체 철거)의 자재는 몰에 올리지 않습니다. 진단 결과에서도 이 공정은 '업체 견적 검증'으로 연결됩니다.

## 2. 판매처별 제휴 수단

| 판매처 | 제휴 수단 | 외부 웹사이트 사용 | 메모 |
|---|---|---|---|
| 쿠팡 | 쿠팡 파트너스 | 가능 (사이트를 채널로 등록) | 주 수익원. 기본 수수료 3%로 알려져 있고 카테고리별로 다를 수 있음. 클릭 후 24시간 내 구매가 실적으로 인정되는 구조 |
| 네이버쇼핑 | 네이버 쇼핑커넥트 | 확인 필요 | 2025년 7월 정식 출시. 판매자가 상품과 수익 배분율을 정하고, 크리에이터(블로그·클립 등)가 링크를 받아 홍보하는 구조. 외부 사이트 채널 인정 여부는 가입 시 확인 |
| 오늘의집 | 오늘의집 큐레이터 | 확인 필요 | 개인 공유 링크 클릭 후 24시간 내 구매 실적. 본인 SNS 공유 중심으로 안내됨 |
| 11번가·G마켓 등 | 링크프라이스 등 제휴 네트워크 | 가능 (사이트 등록 후 광고주별 승인) | 광고주마다 조건이 다름. 관리 화면에서 `pro:` 키나 판매처 키로 등록 가능 |
| 다나와 | 없음 | — | 최저가 비교용. 수익 없음 |

관리 화면은 쿠팡·네이버쇼핑·오늘의집 링크를 받을 수 있고, 등록 가능한 도메인은 서버에서 제한합니다(`functions/api/aff-links.js`의 `ALLOW`).

## 3. 쿠팡 파트너스 시작 순서

1. **가입**: partners.coupang.com → 쿠팡 계정 로그인 → 연락처·정산 계좌 등록. 법인(주식회사 블랭크)으로 정산하려면 사업자 회원으로 가입합니다. 사업자는 부가세 포함 정산과 세금계산서 역발행을 위해 공동인증서가 필요하다고 안내됩니다.
2. **채널 등록**: 이 홈페이지 주소를 활동 채널로 등록합니다. 심사 때 링크 활동과 대가성 문구가 보이는 화면이 필요합니다. 스스로몰·키트 페이지 상단의 '제휴 링크 안내' 박스가 그 문구입니다.
3. **링크 만들기**: 관리 화면(`/admin`) → 스스로몰 링크 → '검색 URL 복사' → 쿠팡 파트너스 '링크 생성'에 붙여넣기 → 만들어진 `https://link.coupang.com/a/…` 주소를 칸에 붙여넣고 '변경 저장'.
4. **최종 승인**: 누적 판매 금액이 15만 원을 넘으면 최종 심사가 진행되고, 최종 승인 후에 정산과 API 사용이 열린다고 안내됩니다.
5. **API 일괄 변환**: 최종 승인 후 발급받은 Access Key·Secret Key를 Cloudflare 환경변수에 넣으면, 관리 화면의 '쿠팡 API로 미등록 일괄 변환'으로 한 번에 최대 60개씩 변환·저장됩니다.

### 우선순위
처음부터 160개를 다 만들 필요는 없습니다. 관리 화면에서 범위를 '스스로몰 상품', 정렬을 '키트 상품 먼저'로 두면 키트에 들어간 상품부터 보입니다. 트래픽이 생기면 '클릭 많은 순'으로 바꿔 실제로 많이 누르는 링크부터 만듭니다.

## 4. 반드시 지킬 표시·운영 원칙

- **대가성 표시**: 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」은 경제적 이해관계를 게시물의 제목 또는 첫 부분에 명확하게 표시하도록 합니다. '소정의 수수료를 받을 수 있음' 같은 조건부·모호한 표현은 명확하지 않은 표시의 예로 듭니다. 스스로몰·키트·자료실 페이지 상단의 안내 박스와 각 링크의 '제휴' 표시가 이 역할을 합니다. 페이지를 새로 만들 때도 상단 안내 박스를 유지하세요.
- **쿠팡 문구**: 쿠팡 파트너스 링크가 있는 페이지에는 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 문구가 들어가 있어야 합니다(안내 박스에 포함).
- **배너·위젯·자동 이동 금지**: 2026년 6월 개인정보보호위원회는 쿠팡에 과징금을 부과하면서, 쿠팡 광고가 실린 외부 페이지 방문만으로 방문 기록이 수집된 점과 '납치광고'(닫기 버튼 위 투명 버튼, 몇 초 뒤 자동 이동) 관리 소홀을 문제 삼았습니다. 스스로몰은 판매처 배너·다이내믹 위젯·스크립트를 넣지 않고, 사용자가 누른 텍스트 링크만 판매처로 이동합니다. 이 원칙을 바꾸지 마세요.
- **링크 형태**: 링크는 판매처 도구(링크 생성·API)로 만든 것만 씁니다. 단축 URL·리다이렉트로 감싸지 않습니다. 사이트의 클릭 기록은 이동을 막지 않는 별도 기록(`/api/click`)입니다.
- **판정과 분리**: 수수료율을 상품 선정 기준으로 쓰지 않습니다. 판정(◎○△×)과 추천 근거는 자료실 원본(셀프시공 총정리)을 따릅니다.

## 5. Cloudflare 설정 (이미 D1을 연결했다면 추가 작업 없음)

| 항목 | 값 | 비고 |
|---|---|---|
| D1 바인딩 | `DB` | 기존 설정 그대로. 스스로몰 테이블(`aff_links`, `aff_clicks`)은 처음 호출될 때 자동으로 만들어집니다 |
| 환경변수 `ADMIN_KEY` | 긴 임의 문자열 | 관리 화면 로그인 키 |
| 환경변수 `COUPANG_ACCESS_KEY` | 쿠팡 파트너스 API Access Key | 최종 승인 후. 선택 |
| 환경변수 `COUPANG_SECRET_KEY` | 쿠팡 파트너스 API Secret Key | 최종 승인 후. **암호화(Encrypt)로 저장** |
| 환경변수 `COUPANG_SUB_ID` | 예: `seuseurolab` | 선택. 채널 구분용 |
| 환경변수 `AFF_ALLOW_ANY` | `1` | 선택. 허용 목록 밖의 판매처 도메인도 등록하려면 |

환경변수를 바꾼 뒤에는 Deployments에서 최신 배포를 다시 실행해야 적용됩니다.

## 6. 데이터베이스 없이 운영하려면

관리 화면 → '링크 파일 내보내기'로 받은 `mall-links.js`를 GitHub 저장소의 `assets/js/mall-links.js`에 덮어쓰면, D1 없이도 같은 링크가 적용됩니다. D1을 쓰는 경우에도 가끔 내보내서 백업해 두면 좋습니다.

## 7. 성과 보는 법

- **사이트 안**: 관리 화면 '클릭 통계' — 최근 30일 구매 버튼 클릭, 제휴 링크 클릭, 많이 누른 검색어, 페이지별 클릭. 개인 식별 정보는 저장하지 않습니다.
- **판매처**: 실제 구매·수수료는 쿠팡 파트너스 등 각 프로그램의 리포트에서 확인합니다.
- **구조식** (숫자를 가정하지 않고 추적할 지표): 월 수수료 ≈ 구매 버튼 클릭 수 × 판매처 구매 전환율 × 평균 주문 금액 × 수수료율. 사이트가 직접 바꿀 수 있는 것은 앞의 두 가지(클릭, 전환)이고, 키트 구성·수량 안내·구매 목록이 전환을 높이는 장치입니다.

## 8. 상품·키트 수정

상품·키트 데이터는 `assets/js/mall-data.js`, 키트 상세 페이지는 `kit-*.html`입니다. 원본은 자료실 엑셀(셀프시공 총정리)이며, 엑셀을 고치면 두 파일과 키트 페이지를 함께 다시 생성해야 합니다. 수정본 엑셀을 주시면 다시 만들어 드립니다.

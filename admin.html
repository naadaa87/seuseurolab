스스로연구소 관리

스스로몰 제휴 링크 등록, 구매 링크 클릭 통계, 상담 접수 내역 다운로드. 이 페이지는 검색에 노출되지 않습니다.

연결 상태

관리 키는 이 탭에만 기억되고, 탭을 닫으면 지워집니다.

링크 등록 순서

  1. 쿠팡 파트너스에 가입하고 사이트(이 홈페이지 주소)를 채널로 등록합니다.
  2. 아래 표에서 검색 URL 복사 → 쿠팡 파트너스 링크 생성에 붙여넣기 → 만들어진 link.coupang.com 주소를 칸에 붙여넣습니다.
  3. 변경 저장을 누르면 몰·키트·자료실의 같은 검색어 버튼에 바로 적용되고 '제휴' 표시가 붙습니다.
  4. 최종 승인 뒤 API 키를 받으면 쿠팡 API로 일괄 변환으로 한 번에 처리할 수 있습니다.

무엇부터 만들까

범위를 '스스로몰 상품'으로 두고 정렬을 '클릭 많은 순'으로 바꾸면, 실제로 많이 누르는 링크부터 보입니다. 키트에 들어간 상품이 위쪽에 먼저 정렬됩니다. 네이버쇼핑·오늘의집 제휴 링크가 생기면 판매처를 바꿔 같은 방식으로 등록합니다.


    
검색어 · 쓰이는 곳클릭(30일)제휴 링크작업

    
여러 개 한 번에 붙여넣기
한 줄에 검색어, 링크 형식으로 붙여넣습니다. 탭으로 구분해도 됩니다. 판매처는 위에서 고른 것이 적용되고, naver:검색어, 링크처럼 앞에 판매처를 적으면 그 판매처로 저장합니다. 링크 칸을 비워 저장하면 등록이 해제됩니다.

페이지클릭

    

    
클릭은 이 사이트에서 구매 버튼을 누른 횟수입니다. 실제 구매와 수수료는 쿠팡 파트너스 등 각 제휴 프로그램의 리포트에서 확인합니다. 클릭 기록에는 개인 식별 정보가 없습니다.

  


  

    
상담·신청 접수 내역
문의, 실행 리포트 신청, 견적서 검증 신청을 CSV로 내려받습니다. 엑셀에서 바로 열립니다. 상태(status)·메모(note)는 D1 콘솔에서 수정하거나, 이후 관리 화면이 생기면 거기서 관리합니다.

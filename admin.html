          쿠팡 실적 입력

          구매는 쿠팡 안에서 일어나서 이 사이트가 직접 볼 수 없습니다. 쿠팡 파트너스 → 리포트에서 날짜별 실적을 복사해 아래에 붙여넣으면 저장되고, 위의 구매 전환·수익 지표가 계산됩니다. 최종 승인 후 API 키를 등록하면 '쿠팡에서 불러오기'로 자동으로 채웁니다.

          리포트 붙여넣기

          첫 줄에 '날짜, 클릭, 주문, 취소, 금액, 수익' 같은 제목이 있으면 열 순서를 알아서 맞춥니다. 제목이 없으면 위 예시 순서로 읽습니다.

        지표는 이렇게 계산합니다
        
          
          
          방문자
          하루 단위로 같은 사람을 한 번만 셉니다. 기간 합계는 날마다 센 값을 더한 것이라 같은 사람이 이틀 오면 2로 셉니다. 사람을 식별하는 값은 저장하지 않습니다.
          
          
          방문
          한 브라우저 탭에서 30분 안에 이어진 페이지 보기 묶음입니다.
          
          
          평균 체류시간
          방문 한 번 동안 화면이 실제로 보이던 시간의 평균입니다. 5분 넘게 아무 조작이 없으면 그 뒤는 세지 않습니다. 페이지 평균 체류는 페이지 한 쪽 기준입니다.
          
          
          이탈률
          참여하지 않은 방문의 비율입니다. 2쪽 이상 봤거나, 10초 이상 머물렀거나, 쿠팡 링크를 누른 방문을 참여 방문으로 봅니다. 상품 페이지에서 바로 쿠팡으로 넘어간 방문은 이탈이 아닙니다.
          
          
          쿠팡 클릭률
          쿠팡 링크를 한 번이라도 누른 방문 ÷ 전체 방문. 페이지별 클릭률은 쿠팡 클릭 ÷ 그 페이지의 페이지뷰입니다.
          
          
          구매 전환·전환율
          쿠팡 파트너스 리포트의 주문 수와, 주문 수 ÷ 쿠팡이 집계한 클릭 수입니다. 쿠팡 클릭 값을 입력하지 않은 기간은 이 사이트에서 센 쿠팡 클릭으로 나눕니다. 쿠팡은 링크를 누른 뒤 24시간 안의 다른 상품 구매도 실적에 넣습니다.
          
          
          클릭당 수익(EPC)
          수익 ÷ 쿠팡이 집계한 클릭 수.
          
          
          제외되는 방문
          검색 로봇, 브라우저의 추적 거부(Do Not Track·GPC)를 켠 방문, 이 화면에서 '내 방문 제외'를 켠 브라우저.
          
        
          
      
          
    
          

    
          
      
          내 방문 제외
          
      
          운영자가 사이트를 둘러본 기록이 통계에 섞이지 않게 합니다. 이 브라우저에만 적용되므로 휴대폰 등 다른 기기에서도 이 화면을 열어 한 번씩 켜 주세요.
          
      
          
    
          
  
          

  
          
    
          
      
          링크 등록 순서
          1. 쿠팡 파트너스에 가입하고 사이트(이 홈페이지 주소)를 채널로 등록합니다.
          2. 아래 표에서 검색 URL 복사 → 쿠팡 파트너스 링크 생성에 붙여넣기 → 만들어진 link.coupang.com 주소를 칸에 붙여넣습니다.
          3. 변경 저장을 누르면 몰·키트·자료실의 같은 검색어 버튼에 바로 적용되고 '제휴' 표시가 붙습니다.
          4. 최종 승인 뒤 API 키를 받으면 쿠팡 API로 일괄 변환으로 한 번에 처리할 수 있습니다.
          
      
          무엇부터 만들까
          범위를 '스스로몰 상품'으로 두고 정렬을 '클릭 많은 순'으로 바꾸면, 실제로 많이 누르는 링크부터 보입니다. 키트에 들어간 상품이 위쪽에 먼저 정렬됩니다. 스스로몰 카드의 큰 버튼은 '대표 상품 링크', 작은 버튼은 '검색 결과 링크'를 씁니다. 링크 종류를 바꿔 각각 관리합니다.
          
    
          
    
          
      
      
      
      
      
      
    
          
    
          
    
          
    
          검색어 · 쓰이는 곳클릭(30일)제휴 링크작업
          
    
          여러 개 한 번에 붙여넣기
          한 줄에 검색어, 링크 형식으로 붙여넣습니다. 탭으로 구분해도 됩니다. 링크 종류는 위에서 고른 것이 적용됩니다. 대표 상품 링크는 @검색어, 링크처럼 앞에 @를 붙여도 됩니다. 링크 칸을 비워 저장하면 등록이 해제됩니다.

          페이지클릭
          
    
          
    
          클릭은 이 사이트에서 구매 버튼을 누른 횟수입니다. 실제 구매와 수수료는 쿠팡 파트너스 리포트에서 확인합니다. 클릭 기록에는 개인 식별 정보가 없습니다.
          
  
          

  
          
    
          상담·신청 접수 내역
          문의, 실행 리포트 신청, 견적서 검증 신청을 CSV로 내려받습니다. 엑셀에서 바로 열립니다. 상태(status)·메모(note)는 D1 콘솔에서 수정하거나, 이후 관리 화면이 생기면 거기서 관리합니다.
